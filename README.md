Fake Job Detection Using Machine Learning

About the Project

Fake Job Detection is a machine learning-based project designed to identify fake and genuine job postings.

The main goal of this project is to help job seekers avoid fraudulent job advertisements and find safer employment opportunities.

Technologies Used

- Python
- Machine Learning
- Flask
- HTML
- CSS

Project Features

- Detect fake job postings.
- Classify job advertisements.
- Simple and user-friendly web interface.
- Machine learning-based prediction.

Project Structure

fake-job-detection/
│
├── app.py
└── README.md

How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Run the Flask application.

python app.py

Project Goal

To improve online job safety by detecting fraudulent job postings using Machine Learning.
